# Spec Delta

## MODIFIED Requirements

### Requirement: Список трат всех членов семьи
Панель SHALL показывать таблицу трат, полученную из `GET /expenses`, в порядке ответа API. В строке: владелец, сумма, категория, дата и время траты, комментарий. Таблица SHALL показывать одну страницу выдачи (размер страницы 50), а не пытаться загрузить все траты.

#### Scenario: Траты двух членов семьи
- **WHEN** в API есть траты членов семьи `123` и `456`, фильтры не заданы
- **THEN** в таблице есть траты обоих в том же порядке, что в ответе API

#### Scenario: Больше одной страницы
- **WHEN** в API 120 трат
- **THEN** в таблице первые 50, запрос содержит `limit=50` и `offset=0`

## ADDED Requirements

### Requirement: Постраничная навигация
Панель SHALL показывать общее количество трат из заголовка `X-Total-Count`, номер текущей страницы и кнопки перехода на предыдущую и следующую страницы, недоступные на границах. Номер страницы SHALL храниться в адресе страницы вместе с фильтрами. Смена любого фильтра SHALL сбрасывать страницу на первую. Если после удаления трата последней на странице пропала, панель SHALL перейти на предыдущую страницу.

#### Scenario: Переход на вторую страницу
- **WHEN** в API 120 трат, пользователь нажимает «Вперёд»
- **THEN** запрос содержит `limit=50` и `offset=50`, адрес содержит номер страницы 2, видно «51–100 из 120»

#### Scenario: Смена фильтра
- **WHEN** открыта третья страница, пользователь выбирает категорию «транспорт»
- **THEN** запрос идёт с `offset=0`, показана первая страница

#### Scenario: Границы
- **WHEN** открыта первая страница
- **THEN** кнопка «Назад» недоступна; на последней странице недоступна «Вперёд»

#### Scenario: Удалена последняя трата на странице
- **WHEN** на третьей странице осталась одна трата и она удалена
- **THEN** панель показывает вторую страницу

#### Scenario: Прямая ссылка
- **WHEN** открывается адрес с номером страницы 2 и фильтром по категории
- **THEN** сразу запрашивается `offset=50` с этой категорией
