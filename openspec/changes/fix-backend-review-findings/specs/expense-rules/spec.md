# Spec Delta

## MODIFIED Requirements

### Requirement: Правила для операций одного члена семьи
Получение, список, изменение и удаление трат в пределах одного члена семьи SHALL проверять сумму, категорию, дату изменения, длину комментария, период фильтра и параметры страницы по тем же правилам и с теми же доменными ошибками, что и общие операции. Чужая трата SHALL давать ошибку «трата не найдена».

#### Scenario: Изменение своей траты с нулевой суммой
- **WHEN** член семьи `A` изменяет свою трату, указав сумму `0`
- **THEN** возвращается ошибка «недопустимая сумма», трата не меняется

#### Scenario: Список своих трат с неверным периодом
- **WHEN** член семьи `A` запрашивает свой список с началом позже конца
- **THEN** возвращается ошибка «некорректная дата»

#### Scenario: Изменение чужой траты
- **WHEN** член семьи `A` изменяет трату члена семьи `B` с корректными полями
- **THEN** возвращается ошибка «трата не найдена»

## ADDED Requirements

### Requirement: Параметры страницы
Лимит страницы SHALL быть целым от 1 до 500, смещение — целым не меньше 0. Иначе SHALL возвращаться ошибка «некорректная страница». Проверка выполняется до обращения к хранилищу.

#### Scenario: Лимит вне диапазона
- **WHEN** список запрашивается с лимитом `0` или `501`
- **THEN** возвращается ошибка «некорректная страница», хранилище не вызывается

#### Scenario: Отрицательное смещение
- **WHEN** список запрашивается со смещением `-1`
- **THEN** возвращается ошибка «некорректная страница»

#### Scenario: Граничные значения
- **WHEN** список запрашивается с лимитом `500` и смещением `0`
- **THEN** ошибки нет

### Requirement: Длина комментария
Комментарий траты SHALL сохраняться без пробелов по краям и содержать после этого не более 200 символов (рун). Иначе при создании и изменении SHALL возвращаться ошибка «недопустимый комментарий», и ничего не сохраняется.

#### Scenario: 201 символ
- **WHEN** создаётся трата с комментарием из 201 символа
- **THEN** возвращается ошибка «недопустимый комментарий»

#### Scenario: 200 символов
- **WHEN** создаётся трата с комментарием из 200 кириллических символов
- **THEN** трата создаётся

#### Scenario: Пробелы по краям
- **WHEN** создаётся трата с комментарием из 200 символов, окружённым пробелами
- **THEN** трата создаётся, комментарий сохранён без пробелов по краям

#### Scenario: Изменение комментария
- **WHEN** у существующей траты комментарий меняется на строку из 201 символа
- **THEN** возвращается ошибка «недопустимый комментарий», трата не меняется
