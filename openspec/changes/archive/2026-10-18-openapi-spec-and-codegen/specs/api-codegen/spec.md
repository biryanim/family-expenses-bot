# Spec Delta

## Purpose

Определяет, как из спецификации `api/openapi.yaml` получается серверный Go-код: проверка спецификации, воспроизводимость генерации и обращение со сгенерированными файлами.

## ADDED Requirements

### Requirement: Спецификация проходит валидацию
`api/openapi.yaml` SHALL быть валидным документом OpenAPI 3.0.3. Проверка SHALL входить в `go test ./...`, чтобы невалидная спецификация роняла тесты без отдельных инструментов.

#### Scenario: Валидная спецификация
- **WHEN** запускается `go test ./...` с текущей спецификацией
- **THEN** проверка спецификации проходит

#### Scenario: Сломанная спецификация
- **WHEN** в спецификации есть ссылка `$ref` на несуществующую схему или ответ без описания
- **THEN** `go test ./...` падает с сообщением об ошибке спецификации

### Requirement: Генерация одной командой
Серверный код (модели, интерфейс strict-сервера и роутинг под chi) SHALL генерироваться из `api/openapi.yaml` командой `go generate ./...`; `make generate` делает то же самое. Генератор SHALL запускаться как зафиксированная в `go.mod` tool-зависимость, без глобальной установки.

#### Scenario: Генерация на чистой машине
- **WHEN** на машине с Go из `go.mod` и без установленного `oapi-codegen` запускается `make generate`
- **THEN** генерация завершается успешно

### Requirement: Воспроизводимость генерации
Повторный запуск `go generate ./...` на неизменённой спецификации SHALL NOT изменять ни один файл в репозитории.

#### Scenario: Повторный запуск
- **WHEN** после закоммиченной генерации снова запускается `go generate ./...`
- **THEN** `git status --porcelain` пуст

### Requirement: Сгенерированный код в репозитории
Сгенерированные файлы SHALL иметь суффикс `.gen.go`, лежать в отдельном пакете внутри `internal/transport/http`, коммититься в репозиторий и не править руками. Сборка (`go build ./...`, `docker build`) SHALL NOT запускать генератор.

#### Scenario: Сборка образа
- **WHEN** выполняется `docker compose build`
- **THEN** образ собирается из закоммиченного сгенерированного кода, генератор не вызывается

#### Scenario: Сборка проекта
- **WHEN** выполняется `go build ./...`
- **THEN** сборка проходит со сгенерированным кодом

#### Scenario: Ручная правка
- **WHEN** сгенерированный файл отредактирован руками, а спецификация не менялась
- **THEN** `go generate ./...` перезаписывает правку, и `git diff` её показывает
