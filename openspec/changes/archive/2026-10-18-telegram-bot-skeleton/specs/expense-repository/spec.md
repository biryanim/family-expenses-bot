# Spec Delta

## ADDED Requirements

### Requirement: Сохранение члена семьи
Слой доступа SHALL сохранять члена семьи по Telegram ID с `username`, `first_name` и `last_name`: создавать запись, если её нет, иначе обновлять эти три поля. `updated_at` SHALL выставляться в текущее время, только если хотя бы одно из полей изменилось. `created_at` при обновлении не меняется. Ошибки хранилища возвращаются с контекстом операции.

#### Scenario: Новый член семьи
- **WHEN** сохраняется член семьи `123` с `username` = `ivan`, `first_name` = `Иван`, `last_name` = `""`, а записи о нём нет
- **THEN** в хранилище появляется запись с этими данными, заполненным `created_at` и пустым `updated_at`

#### Scenario: Профиль не изменился
- **WHEN** член семьи `123` сохраняется повторно с теми же данными
- **THEN** запись остаётся одна, `created_at` и `updated_at` не меняются

#### Scenario: Профиль изменился
- **WHEN** член семьи `123` сохраняется с `username` = `ivan_new`
- **THEN** у записи `username` = `ivan_new`, `updated_at` заполнен, `created_at` прежний

#### Scenario: Сбой хранилища
- **WHEN** при сохранении хранилище возвращает ошибку соединения
- **THEN** возвращается ошибка, которая не является доменной
