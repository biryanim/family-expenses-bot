# Spec Delta

## ADDED Requirements

### Requirement: Последняя добавленная трата члена семьи
Слой доступа SHALL возвращать трату члена семьи с наибольшим порядком добавления (по `id`) среди его трат, со всеми полями. Если у члена семьи нет трат, SHALL возвращаться ошибка «трата не найдена». Ошибки хранилища возвращаются с контекстом операции.

#### Scenario: Несколько трат
- **WHEN** у члена семьи `A` траты с `id` `3` (дата сегодня) и `5` (дата вчера)
- **THEN** возвращается трата `5`

#### Scenario: Трата другого члена семьи
- **WHEN** у `A` трата `5`, у `B` трата `8`
- **THEN** для `A` возвращается трата `5`

#### Scenario: Нет трат
- **WHEN** у члена семьи нет трат
- **THEN** возвращается ошибка «трата не найдена»

#### Scenario: Сбой хранилища
- **WHEN** хранилище возвращает ошибку соединения
- **THEN** возвращается ошибка, которая не является доменной
