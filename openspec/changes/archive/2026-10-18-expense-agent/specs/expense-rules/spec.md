# Spec Delta

## ADDED Requirements

### Requirement: Правила для операций одного члена семьи
Получение, список, изменение и удаление трат в пределах одного члена семьи SHALL проверять сумму, категорию, дату изменения и период фильтра по тем же правилам и с теми же доменными ошибками, что и общие операции. Чужая трата SHALL давать ошибку «трата не найдена».

#### Scenario: Изменение своей траты с нулевой суммой
- **WHEN** член семьи `A` изменяет свою трату, указав сумму `0`
- **THEN** возвращается ошибка «недопустимая сумма», трата не меняется

#### Scenario: Список своих трат с неверным периодом
- **WHEN** член семьи `A` запрашивает свой список с началом позже конца
- **THEN** возвращается ошибка «некорректная дата»

#### Scenario: Изменение чужой траты
- **WHEN** член семьи `A` изменяет трату члена семьи `B` с корректными полями
- **THEN** возвращается ошибка «трата не найдена»

### Requirement: Последняя трата члена семьи
Последней тратой члена семьи SHALL считаться его трата, добавленная позже всех остальных, независимо от даты траты. Если трат нет, SHALL возвращаться ошибка «трата не найдена». Траты других членов семьи не учитываются.

#### Scenario: Последняя добавленная
- **WHEN** член семьи `A` добавил трату с датой сегодня, затем трату с датой вчера
- **THEN** последней считается трата с датой вчера

#### Scenario: Чужая трата добавлена позже
- **WHEN** член семьи `A` добавил трату, затем член семьи `B` добавил свою
- **THEN** последняя трата `A` — его собственная

#### Scenario: Нет трат
- **WHEN** у члена семьи нет ни одной траты
- **THEN** возвращается ошибка «трата не найдена»
