# Spec Delta

## ADDED Requirements

### Requirement: Часовой пояс приложения
Часовой пояс, в котором агент определяет текущую дату и границы дней, SHALL задаваться стандартной переменной окружения `TZ`. В `.env.example` SHALL быть `TZ=Europe/Moscow`. Если `TZ` не задан, используется часовой пояс окружения (в контейнере — UTC).

#### Scenario: Московское время ночью
- **WHEN** `TZ=Europe/Moscow`, и пользователь пишет `кофе 350` в 01:30 по Москве 18 октября 2026 (22:30 UTC 17 октября)
- **THEN** трата записывается датой 18 октября

#### Scenario: TZ не задан
- **WHEN** приложение запущено без `TZ` в контейнере
- **THEN** текущая дата для агента считается по UTC
