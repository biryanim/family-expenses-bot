# Spec Delta

## MODIFIED Requirements

### Requirement: Список известных членов семьи
Слой доступа SHALL возвращать список всех членов семьи, записанных в хранилище, по возрастанию Telegram ID, включая членов семьи без трат. У каждого члена семьи возвращаются `telegram_id`, `username`, `first_name`, `last_name`, `created_at` и `updated_at`. Если членов семьи нет, возвращается пустой список.

#### Scenario: Члены семьи с тратами и без
- **WHEN** в хранилище есть члены семьи `100` (с тратами) и `50` (без трат)
- **THEN** возвращаются оба в порядке `50`, `100`

#### Scenario: Профиль члена семьи
- **WHEN** в хранилище есть член семьи `50` с `username` = `""`, `first_name` = `Анна`, `last_name` = `""`
- **THEN** он возвращается с этими значениями полей, пустые строки сохраняются как пустые

#### Scenario: Нет членов семьи
- **WHEN** в хранилище нет ни одного члена семьи
- **THEN** возвращается пустой список без ошибки
