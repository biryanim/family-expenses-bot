# Proposal

## Why

В репозитории пока есть только `go.mod`, `AGENTS.md` и OpenSpec. Все следующие изменения (БД, REST API, бот, агент, фронтенд) опираются на общую структуру пакетов, единую точку входа и загрузку конфига. Без каркаса каждое изменение будет заново решать, где что лежит и откуда брать настройки, а ошибка в конфиге будет всплывать поздно и непонятно.

## What Changes

- Создаётся структура папок из `AGENTS.md`: `cmd/app`, `api`, `migrations`, `internal/{entity,usecase,repository,transport/http,transport/telegram,agent,llm,config}`, `web`. Пустые папки держатся через `.gitkeep`.
- Go-модуль уже инициализирован (`go.mod`, модуль `github.com/biryanim/family-expenses-bot`, Go 1.27.0) — используется как есть.
- Точка входа `cmd/app/main.go`: один бинарь, который загружает конфиг, настраивает логирование, пишет стартовую запись и работает до сигнала остановки. REST API и бот будут подключены к нему в следующих изменениях.
- Пакет `internal/config`: чтение конфига из переменных окружения — токен Telegram-бота, `base_url`/`api_key`/`model` LLM, строка подключения к PostgreSQL, порт API, уровень логирования. Обязательные значения проверяются при старте; при отсутствии приложение завершается с понятной ошибкой, перечисляющей все незаданные переменные.
- Структурированное логирование в stdout с настраиваемым уровнем.
- `api/openapi.yaml` — заготовка спецификации (заголовок, без эндпоинтов).
- `Dockerfile` (сборка бинаря) и `docker-compose.yml` (приложение + PostgreSQL) — минимальные, чтобы `docker compose up` поднимал каркас. Фронтенд и nginx в compose добавятся вместе с фронтендом.
- `.gitignore` (в т.ч. `.env`, артефакты сборки, `node_modules`) и `.env.example` со всеми переменными без реальных секретов.

## Capabilities

### New Capabilities
- `app-bootstrap`: запуск приложения — загрузка и валидация конфига из окружения, поведение при некорректном конфиге, логирование, корректная остановка по сигналу.

## Impact

- Новый код: `cmd/app/main.go`, `internal/config/`.
- Новые файлы инфраструктуры: `Dockerfile`, `docker-compose.yml`, `.gitignore`, `.env.example`, `api/openapi.yaml`, `.gitkeep` в пустых папках.
- Внешние зависимости не добавляются: на этом шаге хватает стандартной библиотеки. `chi`, `pgx`, `goose`, `go-telegram/bot` появятся в `go.mod` вместе с кодом, который их использует.
- Вне скоупа: схема БД и миграции, HTTP-сервер и хендлеры, бот, агент, LLM-клиент, фронтенд.
